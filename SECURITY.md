# Security Policy

## Reporting a Vulnerability

The Nope Remote team takes security issues seriously. If you discover a security vulnerability, please do NOT create a public issue.

Please report it privately via GitHub Security Advisories:
Security -> Advisories -> [Report a vulnerability](https://github.com/monuk7735/nope-remote/security/advisories/new)

Please include the following details in your report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Device information, Android OS version, and app version tested.

---

## Response Timeline

- Initial Acknowledgement: Within 48 hours of receipt.
- Assessment & Triage: Within 5 business days.
- Resolution & Release: A patch will be published as soon as reasonably possible.

We appreciate your effort in responsibly disclosing issues to protect our users.
